## 🚀 Projects

### 🕺 Neuro-Trainer for Breakdancing — RAG Assistant
**Stack:** Python, LlamaIndex, OpenAI GPT-3.5, FRED-T5-1.7B, Hugging Face, Google Colab  
Interactive RAG assistant that answers questions about breakdance methodology strictly from a knowledge base. Built with `VectorStoreIndex`, `LLMRerank`, `LongContextReorder`, and `HyDEQueryTransform`. Includes a dual-mode system (precise OpenAI RAG / fun local FRED-T5), safety filtering, full RAG tracing, and hallucination detection.

### 🧠 LLM Hallucination Detection (SMILES-2026)
**Stack:** Python, PyTorch, Qwen2.5-0.5B, Hugging Face Transformers  
Lightweight classifier that detects hallucinations in LLM outputs using internal hidden states. Feature engineering, layer selection, token pooling. Participating in a machine learning competition.

### 📰 Lenta.ru News Headline Classification
**Stack:** Python, Scikit-learn, TensorFlow, TF-IDF, Pandas, Matplotlib  
Multi-class classification of news into 10 categories. Compared logistic regression, random forest, and a fully connected neural network with an Embedding layer. Full pipeline: data cleaning, stratified split, TF-IDF vectorization, training, confusion matrix visualization, and analysis.

### 🤖 QuizBot — Telegram Bot for Python Knowledge Testing
**Stack:** Python 3.12, Aiogram, Yandex Cloud (YDB), boto3  
Serverless bot integrated with Yandex Cloud. Quiz logic, YDB database, webhook handling. Demonstrates async programming and cloud deployment skills.

### ✍️ Handwritten Letter Recognition (A-Z)
**Stack:** Python, TensorFlow, Keras, Git LFS
